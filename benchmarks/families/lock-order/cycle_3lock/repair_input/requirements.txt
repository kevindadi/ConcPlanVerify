Three workers need three shared mutexes. Worker 1 uses A and B, worker 2 uses B and C, worker 3 uses C and A. Each worker holds its two mutexes at the same time, releases them, and returns. Main starts all three and waits. Every interleaving must terminate and all three workers must complete. On completion the program must print exactly one line `DONE done=1` and then exit; it must terminate.
