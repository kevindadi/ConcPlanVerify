## Authority

synchronization and shared-state updates. Use the same function and resource

## Libraries

`std` and the already-linked crate `concir_sync` are allowed. Write
`use concir_sync::Semaphore;` when the design has a semaphore. Do not write
`mod concir_sync` and do not implement a semaphore yourself. Do not use
`std::sync::Semaphore` or `Semaphore::release`; neither exists.

Semaphore API, matching the linked crate:

- `Semaphore::new(n) -> Arc<Semaphore>`
- `acquire(&self) -> Permit` (blocks until a permit is available)
- `try_acquire(&self) -> Option<Permit>`
- `Permit::release(self)` consumes the permit and releases it early
- dropping a `Permit` also releases it once

A CIR `semaphore_acquire` is `acquire`. A CIR `semaphore_release` is either
`permit.release()` or the permit leaving scope. Do not acquire an extra permit
or drop one twice to manufacture events.

Other primitives:

- `Mutex` and `Condvar` from `std::sync`
- `std::sync::mpsc::{channel, sync_channel}` for channels; capacity 0 is rendezvous
- `std::sync::atomic` for CIR atomics
- `std::thread::spawn` plus `join`

Do not mention `cir_trace` and do not declare `mod cir_trace`. Instrumentation
is applied later by the checker.

## Correspondence

- One CIR function is one Rust function. The entry scope starts the threads it names.
- One CIR mutex, condvar, channel, or semaphore is one primitive with that name.
  Do not add a primitive the CIR does not have.
- A CIR `var` lives in the mutex named by its protection edge, or in a local.
  Do not add a new lock for it.
- `condvar_wait` is `while !predicate { guard = cv.wait(guard) }` under the paired mutex.
- After joins, `main` may read shared state only to print the required terminal line.

## Rules

- One file, `fn main`, no `unsafe`, no `#![feature]`.
- Do not make the program sequential and do not delete a critical section.
- Do not use `sleep` or `yield_now` to dodge synchronization.
- Join every spawned thread. Print the terminal line from the requirements.

# Requirements

R1. The design contains one main thread and two short-lived workers.
R2. An independent bystander task also runs and keeps making progress without ever finishing on its own. [U]
R3. The two workers share the same two locks and also use two counting permits to coordinate with each other.
R4. Each worker must hold both locks at the same time while it enters its critical section.
R5. The two workers must use the two permits as a handshake, so that neither takes its second lock before the other has taken its first.
R6. The bystander task must not prevent the two workers from finishing.
R7. At every point during execution, it must still be possible for the first worker to finish.
R8. At every point during execution, it must still be possible for the second worker to finish.
R9. Neither worker may wait forever for a permit or a lock that the other worker never provides.
R10. Every worker must release each lock it holds before it finishes.
R11. The main thread starts all three tasks and only finishes after both workers have finished, even though the bystander may keep running.
R12. The program must print exactly the line `DONE a=1 b=1` and then exit. [U]

use std::sync::{Arc, Mutex};
use std::thread;

use concir_sync::Semaphore;

// main::bystander: an independent task that keeps making progress and never
// finishes on its own.
fn bystander() {
    loop {
        std::hint::spin_loop();
    }
}

fn main() {
    // Shared resources (names from the design).
    let a = Arc::new(Mutex::new(0i32)); // lock a, protects `flag`
    let b = Arc::new(Mutex::new(()));   // lock b
    let sa = Semaphore::new(1);
    let sb = Semaphore::new(1);

    // sa/sb end up with no permits in flight: worker a releases sa and worker b
    // releases sb, so each worker already holds the permit it later releases.
    let permit_sa = sa.acquire();
    let permit_sb = sb.acquire();

    // main: spawn bystander, a, b.
    let _hbystander = thread::spawn(bystander);

    let a_ha = Arc::clone(&a);
    let b_ha = Arc::clone(&b);
    let sb_ha = Arc::clone(&sb);
    let ha = thread::spawn(move || {
        let mut guard_a = a_ha.lock().unwrap();     // s1: lock a
        permit_sa.release();                        // s2: release sa
        drop(guard_a);                              // s3: unlock a
        let _permit_sb = sb_ha.acquire();           // s4: acquire sb
        let mut guard_a = a_ha.lock().unwrap();     // s5: lock a
        let guard_b = b_ha.lock().unwrap();         // s6: lock b
        *guard_a = 1;                               // s7: write flag = 1
        drop(guard_b);                              // s8: unlock b
        drop(guard_a);                              // s9: unlock a
    });

    let a_hb = Arc::clone(&a);
    let b_hb = Arc::clone(&b);
    let sa_hb = Arc::clone(&sa);
    let hb = thread::spawn(move || {
        let guard_b = b_hb.lock().unwrap();         // s1: lock b
        permit_sb.release();                        // s2: release sb
        drop(guard_b);                              // s3: unlock b
        let _permit_sa = sa_hb.acquire();           // s4: acquire sa
        let mut guard_a = a_hb.lock().unwrap();     // s5: lock a
        let guard_b = b_hb.lock().unwrap();         // s6: lock b
        *guard_a = 1;                               // s7: write flag = 1
        drop(guard_b);                              // s8: unlock b
        drop(guard_a);                              // s9: unlock a
    });

    // main: join a, then b. The bystander is left running.
    ha.join().unwrap();
    hb.join().unwrap();

    println!("DONE a=1 b=1");
}
