```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    // Shared resources: a and b (R1: two mutexes contended by both workers)
    let a = Arc::new(Mutex::new(()));
    let b = Arc::new(Mutex::new(()));

    // R1: main task starts a group of two workers w1 and w2
    // R5: both workers take the mutexes in the same order (a, then b),
    //     so no wait cycle can form.
    // R6: a worker that cannot take a held mutex waits (Mutex::lock blocks).
    // R7: fixed lock ordering guarantees every interleaving terminates.

    let a1 = Arc::clone(&a);
    let b1 = Arc::clone(&b);
    let w1 = thread::spawn(move || {
        // R2: take a, then b; at this point worker holds both at the same time
        let _ga = a1.lock().unwrap();
        let _gb = b1.lock().unwrap();
        // R3: both guards drop here, releasing each mutex once work is finished
    });

    let a2 = Arc::clone(&a);
    let b2 = Arc::clone(&b);
    let w2 = thread::spawn(move || {
        // R2: take a, then b; at this point worker holds both at the same time
        let _ga = a2.lock().unwrap();
        let _gb = b2.lock().unwrap();
        // R3: both guards drop here, releasing each mutex once work is finished
    });

    // R8: the group finishes only after both workers have completed
    w1.join().unwrap();
    w2.join().unwrap();

    // R9: print exactly this line, then exit
    println!("DONE done=1");
}
```

Notes on how the requirements are met:

- **R1**: `main` spawns exactly two threads, `w1` and `w2`, both contending for mutexes `a` and `b`.
- **R2**: Each worker locks `a` and then `b`, so between the two `lock()` calls and the end of the scope it holds both simultaneously.
- **R3**: The `MutexGuard` values drop at the end of each closure, releasing each mutex exactly once, after the work is done.
- **R4**: Guaranteed by `std::sync::Mutex` semantics — only one holder at a time.
- **R5**: Both workers acquire in the same order (`a` before `b`), so no circular wait can form.
- **R6**: `Mutex::lock()` blocks until the mutex becomes free.
- **R7**: With a consistent global lock order, deadlock is impossible, so all interleavings terminate.
- **R8**: `main` joins both worker handles before proceeding.
- **R9**: The program prints exactly `DONE done=1` and exits.
