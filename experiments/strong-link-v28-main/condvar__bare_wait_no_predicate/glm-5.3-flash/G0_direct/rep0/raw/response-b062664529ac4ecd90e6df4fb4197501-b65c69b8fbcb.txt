```rust
use std::sync::{Arc, Condvar, Mutex};
use std::thread;

fn main() {
    // Shared resources: m (lock), cv (condition variable), ready (shared flag)
    let m = Arc::new(Mutex::new(false));
    let cv = Arc::new(Condvar::new());

    let m_waiter = Arc::clone(&m);
    let cv_waiter = Arc::clone(&cv);

    // waiter role
    let waiter = thread::spawn(move || {
        let mut guard = m_waiter.lock().unwrap();
        // Check the flag first; wait only while the flag is false;
        // re-check after each wake. The lock is released while blocked.
        while !*guard {
            guard = cv_waiter.wait(guard).unwrap();
        }
        // Only pass the wait once the flag is true.
        assert!(*guard);
    });

    let m_notifier = Arc::clone(&m);
    let cv_notifier = Arc::clone(&cv);

    // notifier role
    let notifier = thread::spawn(move || {
        let mut guard = m_notifier.lock().unwrap();
        // Set the shared flag to true while holding the lock,
        // signal the condition variable, then release the lock.
        *guard = true;
        cv_notifier.notify_one();
        drop(guard);
    });

    // Both roles run at the same time; wait for both to finish.
    waiter.join().unwrap();
    notifier.join().unwrap();

    // The flag is true in every schedule.
    assert!(*m.lock().unwrap());

    println!("DONE ready=true");
}
```

This satisfies all requirements:

- **R1**: `main` spawns the `waiter` and `notifier` threads, which run concurrently.
- **R2**: One `Mutex` (`m`) and one `Condvar` (`cv`) are shared via `Arc`; the lock guards the boolean `ready` flag.
- **R3**: The notifier sets `ready = true` while holding the lock, calls `notify_one()`, then releases the lock (`drop(guard)`).
- **R4**: The waiter locks, checks `ready` first, and only calls `cv.wait` inside `while !*guard`, so it re-checks the flag after every wake (also protecting against spurious wakeups).
- **R5**: If the notifier signals before the waiter waits, the waiter sees `ready == true` on its first check and never waits — it completes anyway.
- **R6**: The waiter never waits when the flag is already true (the `while` condition), and `Condvar::wait` atomically releases the lock while blocked.
- **R7**: Every interleaving terminates: either the waiter waits and is woken by the signal, or it skips waiting because the flag is already true. Both threads are joined.
- **R8**: The flag is set to true by the notifier in every schedule (asserted before printing).
- **R9**: The waiter's loop only exits when `ready` is true.
- **R10**: The program prints exactly `DONE ready=true` and exits.
