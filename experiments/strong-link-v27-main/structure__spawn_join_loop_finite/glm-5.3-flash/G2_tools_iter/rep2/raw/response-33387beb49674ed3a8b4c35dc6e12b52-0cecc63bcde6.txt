```rust
fn main() {
    // R1: main starts a worker and waits for it to finish, then repeats the cycle.
    // R6: exactly one cycle, so the final count is 1.
    let mut done = 0;

    for _ in 0..1 {
        // R3: start the worker, keep its join handle, and wait for it
        // exactly once before starting the next worker.
        let handle = std::thread::spawn(|| {
            // R2: the worker performs no shared work and shares no
            // mutexes or counters with the main task.
        });

        // R4/R5: the worker always finishes (it does nothing), so the
        // join below always completes and no schedule can stall.
        handle.join().expect("worker panicked");

        done += 1;
    }

    // R6: print exactly this line, then exit.
    println!("DONE done={}", done);
}
```

**How the requirements are satisfied:**

- **R1** — `main` spawns a `worker` thread and immediately joins it; the loop structure models the start-and-wait cycle (run once here, per R6).
- **R2** — the worker closure captures nothing; it performs no work and touches no shared state, mutexes, or counters. The `done` counter lives only in `main`.
- **R3** — each `handle` is joined exactly once, before the next iteration could spawn a new worker.
- **R4/R5** — the worker's body is empty, so it always terminates; `join` therefore always returns, and every interleaving terminates.
- **R6** — the program prints exactly `DONE done=1` and exits.
