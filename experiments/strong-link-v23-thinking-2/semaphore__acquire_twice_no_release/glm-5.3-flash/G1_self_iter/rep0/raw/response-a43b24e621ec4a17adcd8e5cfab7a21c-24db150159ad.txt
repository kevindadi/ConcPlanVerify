## Review

I traced every concurrency path against the requirements:

- **R2** — `Semaphore::new(1)` starts the pool with exactly one permit. ✓
- **R3/R4** — each unit is a strict `acquire` → hold `Permit` → drop cycle; the RAII `Drop` impl fires on normal scope exit *and* on unwind, so releases always match acquires. The permit is never held across a blocking `acquire`, so a worker can't deadlock against itself. ✓
- **R5** — `acquire` blocks in `Condvar::wait`, which atomically releases the internal mutex; `release` only needs the mutex briefly (increment), and it drops the guard *before* `notify_one`, so a woken waiter can immediately re-lock. ✓
- **R6** — the `while *n == 0` loop re-checks the predicate on every wakeup, including spurious ones; `notify_one` is sufficient because each `release` adds exactly one permit and there is at most one permit to hand out at a time; no code path can panic while holding the semaphore's mutex, so the mutex can never be poisoned into a stuck state. Every schedule terminates. ✓
- **R7** — the workers perform no I/O; the only print is the final line, and after both joins all acquires are matched, so the count is back to `1`. ✓
- **R1** — the supervisor spawns `w1` and `w2` and joins both before reading the count. ✓

No defect justifies a change: the wait loop, the notify placement, the RAII guard, and the join-then-read ordering are all correct as written. The complete, verified program:

```rust
use std::sync::{Arc, Condvar, Mutex};
use std::thread;

/// Counting semaphore with a single permit initially (R2).
struct Semaphore {
    permits: Mutex<usize>,
    available: Condvar,
}

impl Semaphore {
    fn new(initial: usize) -> Self {
        Semaphore {
            permits: Mutex::new(initial),
            available: Condvar::new(),
        }
    }

    /// Blocks until a permit is available. While waiting, the internal
    /// mutex is released, so the current holder can still `release` (R5).
    fn acquire(&self) {
        let mut n = self.permits.lock().unwrap();
        while *n == 0 {
            // `wait` atomically releases the mutex and sleeps;
            // re-check on every wakeup, including spurious ones (R6).
            n = self.available.wait(n).unwrap();
        }
        *n -= 1;
    }

    /// Returns one permit. The mutex is held only briefly; it is
    /// dropped before notifying so the woken waiter never queues
    /// behind the notifier.
    fn release(&self) {
        let mut n = self.permits.lock().unwrap();
        *n += 1;
        drop(n);
        self.available.notify_one();
    }
}

/// RAII guard: releases the permit on every path, including
/// early return or panic (R4).
struct Permit<'a> {
    s: &'a Semaphore,
}

impl Drop for Permit<'_> {
    fn drop(&mut self) {
        self.s.release();
    }
}

/// Each work unit is a strict acquire -> work -> release cycle.
/// The permit is never held across an `acquire` call, so a worker
/// can never block on itself (R3, R4, R6).
fn worker(name: &'static str, s: Arc<Semaphore>, units: usize) {
    for i in 0..units {
        s.acquire();
        let _permit = Permit { s: &*s };
        // The work itself: pure computation, no output, so the
        // program's only printed line is the final one (R7).
        let _ = (name, i);
        // `_permit` drops here (or on unwind), releasing exactly once.
    }
}

fn main() {
    // Shared pool begins with exactly one permit (R2).
    let s = Arc::new(Semaphore::new(1));

    // Supervisor launches both workers (R1).
    let s1 = Arc::clone(&s);
    let w1 = thread::spawn(move || worker("w1", s1, 2));

    let s2 = Arc::clone(&s);
    let w2 = thread::spawn(move || worker("w2", s2, 2));

    // Supervisor waits for both workers to finish (R1, R6).
    w1.join().expect("w1 panicked");
    w2.join().expect("w2 panicked");

    // All acquires are matched by releases by the time both threads
    // have been joined, so the count is back to the initial value.
    let done = *s.permits.lock().unwrap();
    println!("DONE done={}", done); // prints exactly `DONE done=1` (R7)
}
```

**Summary of repairs:** none required — the semaphore's wait/notify protocol, the RAII release-on-all-paths guard, and the supervisor's join-before-read ordering already satisfy R1–R7 under every interleaving.
