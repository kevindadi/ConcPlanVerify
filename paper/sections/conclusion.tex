\section{Conclusion}
\label{sec:conclusion}

% 结论先回收全文主线:把并发验证从源码级 alias 困境中抽出来,转向显式、无别名的 CIR,再映射到 CVN 做形式验证.
This paper presented a generate--verify--repair architecture that shifts concurrency reasoning from error-prone source-level alias analysis to an explicit, alias-free intermediate representation, \textsc{Cir}. By capturing synchronization intent---including shared-resource identities and protection relations---\textsc{Cir} enables a deterministic mapping to \textsc{Cvn}, a weighted P/T Petri net with three-valued logic.

% 然后再次强调最终接受条件不是只有 bug-free,还必须满足 goal reachability;这是本文一个重要区别点.
The acceptance criterion for a verified \textsc{Cir} is the
conjunction of bug-freedom and goal reachability. Bug detection answers ``does anything go wrong?'' via pattern matching over the state space. Goal reachability answers ``can the program achieve what it is supposed to?'' via a linear scan over the same state set, corresponding to the resource-derivability question of linear logic. By checking goals only after establishing bug-freedom, the pipeline cleanly separates two failure modes: concurrency defects
that block progress, and semantic regressions that silently remove essential behavior. Our evaluation shows that this lightweight check (under 0.5\,ms) catches semantic regressions that pass all other verification layers.

\paragraph{Future work.}
% 未来工作 1 是补上源码与 CIR 的一致性验证,强化端到端保证.
\textbf{Source--CIR conformance.} An independent extractor that recovers a concurrency skeleton from generated source code and checks structural conformance against the verified \textsc{Cir} would strengthen the end-to-end guarantee.
% 未来工作 2 是支持弱内存语义相关的并发错误.
\textbf{Weak-memory semantics.} Extending the \textsc{Cvn} with fence operations would enable detection of bugs that depend on relaxed atomics.
% 未来工作 3 是把现在的“状态可达目标”推广到更强的“路径次序目标”.
\textbf{Path-sensitive goals.} The current goals check state
reachability. Extending to ordering goals (``$x$ must be written before $y$ is read'') would require path-based analysis over the state graph, a natural next step given the existing infrastructure.
